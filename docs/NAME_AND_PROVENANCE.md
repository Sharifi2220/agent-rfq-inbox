# Name, provenance and rights

“OpenQuote Lite” is the historical working name of this reference implementation. An unrelated commercial service at [openquote.net](https://www.openquote.net/) already uses “OpenQuote” for trade-service enquiries. To reduce confusion, this repository uses the descriptive slug `agent-rfq-inbox` and makes no affiliation claim. This is an obvious-conflict check, not trademark clearance. A later public-facing name may need to change.

The idea was proposed in a ChatGPT exchange with the project owner on 2026-10-26. Claude prepared and expanded the original `0.1.0` implementation for the owner. A separate AI review produced `0.1.1rc1`, with documented security, privacy and semantic corrections. This alpha incorporates that review and subsequent Codex changes. The dated concept, original source and review archive remain in the owner’s Google Drive project. [The review report](history/REVIEW_REPORT_2026-10-26_DE.md) records the independent findings.

The project owner explicitly authorized public source release under Apache-2.0. No individual author or copyright holder is invented in project metadata. No third-party source code is knowingly vendored; optional dependencies are installed separately and keep their own licenses. This provenance statement does not replace a jurisdiction-specific intellectual-property or trademark review.
